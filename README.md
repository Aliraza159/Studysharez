tudySharez – Smart Study Material Sharing Platform

StudySharez is a mobile-based educational platform developed to simplify the sharing and management of academic resources between students and instructors. The application provides a centralized environment where instructors can upload study materials and students can access, download, and manage learning content efficiently.

The system is designed to improve communication, accessibility, and organization within academic institutions by offering role-based functionalities for Students, Instructors, and Administrators. StudySharez also supports offline access, allowing students to use downloaded study materials without requiring an internet connection.

The application is developed using the Flutter framework with Firebase integration for authentication, cloud storage, and real-time database management. The system follows an object-oriented approach and focuses on usability, performance, and secure access control.
